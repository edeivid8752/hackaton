# Paleta personalizada — LinceAccess V0.2

En **Configuración > Apariencia**, debajo de las seis paletas predefinidas, abre **Paleta personalizada**.

1. Elige qué vas a colorear: **Fondo**, **Menú lateral** o **Tarjetas**.
2. Arrastra el selector del cuadrado para combinar saturación y brillo. Usa la barra arcoíris para cambiar el tono.
3. Opcionalmente, introduce un color hexadecimal de seis dígitos, como `#481D2B`.
4. Observa la vista previa y pulsa **Usar mi paleta personalizada**. Si ese tema ya está activo, el cambio se refleja de inmediato.
5. Los colores elegidos permanecen guardados localmente con la clave `linceaccess.customPalette.v1`. El tema activo se guarda bajo la clave original `linceaccess.appearance.v1`.

Para volver a colores predefinidos, solo selecciona cualquiera de las seis paletas. **Restablecer colores iniciales** solo restaura la paleta personalizada y no modifica el sistema.

El selector admite ratón, pantalla táctil, flechas del teclado y entrada hexadecimal. No modifica servidor, datos, roles ni guardia. Contraste de textos y botones se adapta a superficies claras u oscuras, aunque cualquier combinación extrema puede reducir legibilidad.

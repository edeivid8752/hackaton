# Entrega del Hackatón LinceCode 2026

Material incluido: memoria técnica de proyecto, manual operativo integral, código fuente web y Android, y Excel de **100 registros ficticios**.

El APK se genera en GitHub Actions. No se incluyen datos personales reales ni credenciales. Para la demostración usar una red local y cuentas ficticias.

Antes de usar fuera del entorno de pruebas, revisar autenticación, privacidad, HTTPS, políticas de retención y procedimientos oficiales de evacuación.

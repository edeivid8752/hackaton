# Acceso Lince — Cambio de identidad visual

- Cambiado el nombre visible del panel lateral y acceso administrativo a **Acceso Lince**.
- El antiguo icono del lince fue reemplazado por el logotipo UAdeO proporcionado por el usuario (`public/assets/uadeo-logo.png`), presentado sobre un fondo oro champán sólido para dar contraste.
- El icono del navegador utiliza exclusivamente el emblema recortado de esa misma imagen.
- Nombre actualizado en pestaña, pantalla de inicio de sesión, pie de página y credenciales de demostración.
- Se conservaron las seis paletas, el editor personalizado, el menú automático, las animaciones y los archivos JS y backend originales.

Si no ves los cambios, haz una recarga forzada del navegador (Ctrl + Shift + R).
